# PHASE 7 — Advanced NPCs + Police + Emergency AI

Built on Phase 6 without requiring a backend.

## Included
- NPC daily schedules based on role and world time
- NPC social/group behavior and player avoidance
- Walking animation motion and role-specific visual details
- Expanded NPC density using the Phase 5 streamed world
- Police wanted system with 5 levels
- Police pursuit, search, arrest attempts, pursuit vehicles
- Wanted-level decay after losing police contact
- Emergency response vehicles (ambulance/fire) with dynamic dispatch
- Mobile/desktop HUD wanted stars
- Existing economy, missions, traffic, streaming and save systems preserved

## Controls
- H: trigger a test crime / increase wanted level
- E: interact
- M: map
- WASD: move/drive

## Performance
AI unit counts are capped, distant units are removed, and the existing quality profiles remain in effect.

## Note
Emergency vehicles are procedural placeholder vehicles. No real-world agency branding is reproduced.
