# Phase 8 — Story & Mission Expansion

This phase expands the game into a reusable mission framework with **20 main missions and 30 side missions**.

## Included
- Sequential 20-mission main story.
- 30 side missions available from the mission journal.
- Reach, vehicle reach, wanted, clear-wanted, crime, weather, time, purchase and property objectives.
- Mission rewards in rupees.
- Mission checkpoint markers.
- Basic dialogue/cutscene overlay for key story beats.
- Mission journal with completion state and side-mission launch.
- Save/load of mission progress.
- GitHub Pages/static deployment compatibility.

The city remains fictionalized/procedural and uses Vizag-inspired place names.
